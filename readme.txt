Eklenti, WooCommerce siparişlerine PDF fatura yüklenmesini ve müşterilerin indirmesini sağlar.

== Description ==
Yönetici panelinden siparişe PDF fatura yükleyebilir, müşteri sipariş detaylarından indirebilir.

== Installation ==
1. Eklentiyi `wp-content/plugins` dizinine yükleyin
2. WordPress admin panelinden etkinleştirin
3. WooCommerce sipariş sayfasındaki E-Fatura kutusunu kullanın

== Frequently Asked Questions ==
= Yalnızca PDF mi desteklenir? =
Evet. Güvenlik nedeniyle yalnızca PDF dosyalarına izin verilir.
